# Mini-VLA 路线图

项目采用“每次只增加一个主要难度”的方式推进。当前最新验收版本是 **V1.3**；V1 至 V1.2 保留为历史回归基线。

## 版本状态

| 版本 | 内容 | 状态 |
|---|---|---|
| V0 | 二维固定指令到达 | 已完成 |
| V1 | 二维红蓝双目标 + 自然语言指令，到达指定目标 | 已完成，回归基线 |
| V1.1 | 二维红蓝双目标抓取并放入固定区域 | 已完成，回归基线 |
| **V1.2** | 64×64 二维红蓝目标抓取放入随机红/蓝区域（fine_tol=0.08） | 已完成验收，历史基线 |
| **V1.3** | 二维三色抓取放置，四维状态输入 | **已按 `official` 标准验收** |
| **V1.5** | 二维移动方块与移动放置区 | **重新规划中，模型已清理** |
| V1.6 | V1.5c 验收后定义下一个单一难点 | 待定 |
| V2.0 | 自然语言解析与更强语言泛化 | 规划中 |

## V1.3 验收与 V1.5 启动

V1.3 当前发布基线为 `v1.3_final.pt`，在固定 `20261105` 场景种子、200 个场景和 1800 次闭环中按唯一 `official` 标准取得 **90.56% (1630/1800)**。历史 93.3% 结果对应的 checkpoint 已不在工作区，不能作为当前可复现模型。验收细节见 [V1.3_RELEASE.md](V1.3_RELEASE.md)。

V1.5 的新目标是加入移动方块和移动放置区，分为单独移动与同时移动三个阶段，保留 V1.3 的三色抓放任务、四维状态接口和 `official` 边长 0.30 落点评分范围。旧静态障碍物 checkpoint 已清理，具体范围见 [V1.5_PLAN.md](V1.5_PLAN.md)。

## V1 基线

V1 的任务是：场景中有一个红色目标和一个蓝色目标，模型根据图像、指令和二维机器人状态，输出二维移动动作，使机器人到达指令指定的目标。

```text
输入：image (64,64,3) + instruction + robot_state [x,y]
输出：action_chunk (4,2)，每步为 [dx,dy]
任务：移动到指令指定颜色的目标
```

V1 保留在仓库中，用于检查 V1.1 的新增功能是否破坏原有的视觉和语言能力。实验记录见 [exp002_natural_language.md](experiments/exp002_natural_language.md)。

## V1.1 正式版本

V1.1 在二维环境中增加抓取、搬运和放置：

```text
输入：image + instruction + [x, y, holding]
输出：action_chunk (4,3)，每步为 [dx, dy, dgrip]
流程：移动到目标 → 闭合 → 搬运 → 打开
```

关键设计：

1. 红色和蓝色目标继续使用 V1 的语言选择机制；
2. 每个场景使用随机机器人起点，避免状态直接泄露目标方向；
3. 训练样本采用严格相邻的 `red_t, blue_t` 反事实配对；
4. `holding` 表示实际夹持状态，`dgrip` 使用固定阈值解码；
5. 搬运过程按每个 tick 的夹爪位移更新目标，禁止瞬移；
6. 数据检查、专家验收、闭环评测和 V1 回归测试都必须通过。

V1.1 的完整设计和接口见 [V1.1_PLAN.md](V1.1_PLAN.md)，正式验收记录见 [V1.1_RELEASE.md](V1.1_RELEASE.md)。
