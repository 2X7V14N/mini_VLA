# V1.3 Final Release

## Selected Model

The current V1.3 release is:

```text
checkpoints/v1.3_final.pt
```

It is a conservative fine-tuning run initialized from
`v1.3_base.pt`. The run increased old expert replay rather
than aggressively amplifying correction phases, because the previous targeted
run regressed in `OPEN` and `MAX_TICKS`.

| Property | Value |
| --- | ---: |
| Model type | `LanguageConditionedMiniVLA3Color` |
| State input | `[x, y, holding, gripper_open]` |
| Action output | `(4, 3)` |
| Best validation loss | `0.033926` |
| Training stop | epoch 23, early stopping |
| Initialization | `v1.3_base.pt` |
| Learning rate | `1e-5` |
| Old replay multiplier | `2` |
| Correction multiplier | `1` |

## Official Closed-Loop Result

The model was evaluated on the fixed official comparison set:

- generated scenes with `seed=20261105`;
- 200 scenes;
- 9 block/zone color combinations per scene;
- 1800 closed-loop trials;
- the unchanged `official` scoring standard.

| Metric | Result |
| --- | ---: |
| Full task success | **90.56% (1630/1800)** |
| Environment-native success | 86.61% (1559/1800) |
| Reached commanded block | 97.8% |
| Captured target | 96.4% |
| Reached destination zone | 93.3% |
| Correct zone among released trials | 97.1% (1630/1679) |
| Random policy success | 0.0% |
| Image-zero ablation | 0.0% |
| Block-instruction shuffle ablation | 0.0% |
| Zone-instruction shuffle ablation | 0.0% |

The official final placement score uses a `0.30 x 0.30` square centered on the
commanded zone. The rollout environment, rendered image, and actions are not
changed by this post-rollout scoring rule.

## Failure Analysis

Failure types:

```text
TARGET_NOT_REACHED: 39
OBJECT_SLIPPED:     47
MAX_TICKS:          58
CLOSE_MISS:         12
ZONE_NOT_REACHED:    9
DROP_OUTSIDE:        5
```

Failure stages:

```text
MOVE_TO_OBJECT: 39
MOVE_TO_ZONE:   56
OPEN:           49
CLOSE:          26
```

The remaining limitation is long-horizon execution after the initial visual
and language decision, especially maintaining the object during transport and
finishing the `OPEN` phase without timing out. The model is therefore accepted
as the current V1.3 baseline, but not described as perfect manipulation.
