# Mini-VLA 路线图与结项状态

> 项目已于 V1.5e 暂时结项。本文记录实际完成状态，不把未来设计误写成已实现功能。

| 版本 | 内容 | 状态 |
|---|---|---|
| V0 | 二维固定指令到达 | 已完成 |
| V1 | 红蓝双目标 + 自然语言指定目标 | 已完成，回归基线 |
| V1.1 | 抓取、搬运、释放与固定放置区 | 已完成，回归基线 |
| V1.2 | 随机红蓝放置区与双颜色角色指令 | 已完成验收 |
| V1.3 | 三色方块、三色放置区、四维状态 | 已按 official 标准验收 |
| **V1.5e** | 目标方块和目标放置区同时移动 | **已完成，79.3% 最终验收** |
| V1.6 | 双动态场景上的障碍物 | 暂缓，未实现 |
| V2.0 | Qwen 语言编码器 | 仅设计，未实现 |

## 最终冻结点

V1.5e 是最终 checkpoint。它在固定的 1,800 条双动态闭环测试上取得
`1428/1800 = 79.3%` 完整成功率。详细结果、模型接口和复现实验见
[V1.5_FINAL.md](V1.5_FINAL.md)；全项目范围见
[PROJECT_CLOSEOUT.md](PROJECT_CLOSEOUT.md)。

## 未来工作（非本项目成果）

- V1.6：在保持 V1.5e 输入接口的前提下，研究障碍物感知、避障专家与闭环安全性。
- V2.0：将字符级语言编码器替换为冻结的 Qwen 语言特征，并单独构造未见表达验证集。

任何重启工作都应新建版本化数据集、固定随机种子、独立验证/测试集和验收报告，
而不是覆盖此结项版本的指标。
