# Mini-VLA 项目结项说明

## 结项范围

本项目至 V1.5e 暂时结项。结项版本实现并验收了一个小型、可复现的二维 VLA：
它从 RGB 图像、中文指令和机器人状态预测连续移动与夹爪动作，在闭环中完成三色
方块到三色放置区的抓取放置任务。

最终验收资产：

| 项目 | 内容 |
|---|---|
| 最终 checkpoint | `checkpoints/v1.5e.pt`（本地实验资产，不提交 Git） |
| 最终结果 | 1428 / 1800，79.3% 完整成功率 |
| 正式数据 | `data/v1.5c/test`，200 场景 × 9 颜色组合 |
| 机器可读报告 | `reports/v1.5e_results.json` |
| 技术归档 | [V1.5_FINAL.md](V1.5_FINAL.md) |

## 版本成果

| 版本 | 增量 | 已验收结果 |
|---|---|---|
| V1 | 图像 + 语言的二维目标到达 | 作为回归基线保留 |
| V1.1 | 夹爪状态与抓取/搬运/释放状态机 | 96.0% 完整成功率 |
| V1.2 | 随机颜色放置区与方块/区域双角色指令 | 95.0% 完整成功率 |
| V1.3 | 三色方块、三色放置区、四维状态 | 90.56% official 完整成功率 |
| V1.5e | 最近四帧时间融合；目标方块和目标区同时运动；闭环纠偏 | **79.3% 双动态完整成功率** |

不同版本的场景难度和评分协议不同，表中百分比只用于展示各阶段各自的验收结果，
不应跨任务直接比较。

## 仓库组织

```text
src/mini_vla/             可导入的环境、渲染、数据集、模型与训练模块
scripts/v1*/              按版本归档的数据生成、训练、评测、演示脚本
configs/                  可复现训练与数据配置
docs/                     计划、验收规范、发布记录与技术归档
reports/                  已选定实验的机器可读结果
checkpoints/              本地权重与轻量元数据（大权重由 Git 忽略）
data/                     本地数据集（由 Git 忽略，可按脚本重建）
```

`scripts/v1_5a/demo_v15e.py` 是最终模型的本地交互入口。它的“全场景动态”视觉
演示用于观察策略，不是正式评测环境。

## 复核顺序

1. 安装项目：`python -m pip install -e ".[train,dev]"`。
2. 运行单元/契约测试：`python -m pytest -q`。
3. 在本地拥有 `v1.5e.pt` 与 `data/v1.5c` 时，按
   [V1.5_FINAL.md](V1.5_FINAL.md) 的命令运行最终闭环评测。
4. 使用 `demo_v15e.py` 进行人工观察；不要把演示中的全对象运动结果写入正式指标。

## 结项后的状态

V1.6（障碍物）和 V2.0（Qwen 语言编码器）仅有设计说明，未纳入已实现成果。若
未来恢复开发，应从冻结的 V1.5e 开始，建立新的数据版本、独立验证/测试划分与
验收标准，避免修改本结项版本的正式报告。
