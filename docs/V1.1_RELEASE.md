# V1.1 正式版本记录

V1.1 是当前仓库的正式版本：二维红蓝双目标抓取、逐 tick 搬运并放置到固定区域。V1 保留为回归基线。

## 版本接口

```text
image:        (64, 64, 3) uint8 RGB
instruction:  红色/蓝色目标自然语言指令
robot_state:  [x, y, holding]
action_chunk: (4, 3) [dx, dy, dgrip]
```

连续 `dgrip` 的统一解码规则为：`<= -0.5` 闭合，`>= +0.5` 张开，中间值保持当前状态。

## 数据基线

| 划分 | rollout | 配对样本 |
|---|---:|---:|
| train | 1000 | 27179 |
| val | 200 | 5548 |
| test | 200 | 5426 |

数据检查结果：`39/39 通过`。train/val/test 没有场景重叠；红蓝样本按同一观测严格相邻配对；搬运位移与夹爪位移逐 tick 一致。

状态泄露检查只统计 `MOVE_TO_OBJECT` 且动作平面位移大于 0.1 的帧：方向 `R² = -0.180`，说明状态不能单独决定目标方向。
