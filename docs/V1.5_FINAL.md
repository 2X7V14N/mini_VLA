# V1.5 最终归档

## 最终模型

```text
checkpoints/v1.5e.pt
```

V1.5e 从 V1.5c 初始化，使用 V1.5c 训练场景中的闭环失败纠偏数据进行
保守微调。推理输入仍是四帧图像历史、语言指令和机器人状态；仿真坐标只
用于离线专家动作和纠偏样本生成。

## 最终评测

测试集固定为 `data/v1.5c/test` 的 200 个场景、9 种颜色组合，共 1,800 条
闭环；结果文件为 `reports/v1.5e_results.json`。

| 指标 | V1.5c | V1.5e 最终 |
|---|---:|---:|
| 完整成功 | 1298/1800 (72.1%) | **1428/1800 (79.3%)** |
| 到达方块 | 99.5% | **99.6%** |
| 捕获目标 | 94.9% | **95.1%** |
| 到达放置区 | 89.0% | **92.7%** |
| DROP_OUTSIDE | 295 | **237** |
| OBJECT_SLIPPED | 107 | **43** |

V1.5f 的 78.4% 结果不满足改进门槛，报告仅作为否定实验记录保留。

## 数据保留

- `data/v1.5c/`：V1.5 双动态 train/val/test 正式数据；
- `data/v1.5e_corrections/`：V1.5e 首轮闭环纠偏数据；
- `data/v1.5f_corrections/`：已删除；
- V1.5a、V1.5c、V1.5f checkpoint：已删除；只保留 `v1.5e.pt`。

## V1.5 结论

V1.5 已完成“移动方块 + 移动放置区”的端到端视觉语言动作学习验证。
主要剩余错误集中在移动放置区附近的最终释放，而不是语言选择或接近方块。
后续不再对 V1.5 做无止境纠偏，直接冻结结果进入 V1.6。
