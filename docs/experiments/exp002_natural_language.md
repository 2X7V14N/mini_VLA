# 实验 002：自然语言泛化（V1）

- **版本**：V1
- **状态**：已完成
- **任务**：二维场景中的红蓝双目标到达
- **权重**：`checkpoints/v1_natural_language.pt`
- **元数据**：`checkpoints/v1_natural_language.json`
- **前置**：[exp001_synthetic_reach.md](exp001_synthetic_reach.md)

## 实验目标

V0 使用固定说法，无法区分模型是在理解颜色，还是在记忆整句文本。V1 保持场景、模型和动作空间不变，只为红色和蓝色目标提供多种训练说法，并用训练中没有出现的说法做闭环评估。

## 数据和接口

```text
image:         (64,64,3) uint8 RGB
instruction:   红色或蓝色目标的自然语言表达
robot_state:   [x,y]，范围 [-1,1]
action_chunk:  (4,2)，四个未来二维位移，范围 [-1,1]
```

每个场景包含一个红色目标、一个蓝色目标和一个绿色机器人。配对样本共享图像和状态，只改变颜色指令及对应动作，避免模型绕过语言通路。

## 结果

训练和验证损失均明显低于忽略语言的基线。置零图像、打乱指令或置零状态都会显著损失性能，说明三路输入都参与了决策。对已见说法、未见但使用已知字符的说法、含新字符的说法均完成闭环评估。

## 结论边界

V1 证明了基本的颜色关键词泛化，但没有证明否定、空间关系、多步指令或复杂句法理解。这些能力不属于当前 V1 任务，也不作为本次清理后的基线承诺。
