# V1.2 正式验收记录

## 结论

V1.2 已通过正式闭环验收。最终模型在 200 个未参与训练的测试场景、每场景 4 种指令组合（共 800 次闭环）上取得 **95.0%（760/800）完整成功率**，超过 90% 门槛。该模型作为当前 V1.2 发布候选；.08_safe 保留为回退基线。

## 冻结接口

输入：image (64, 64, 3) + instruction + robot_state [x, y, holding]
输出：action_chunk (4, 3)，每步 [dx, dy, dgrip]
任务：按指令抓取红/蓝方块，并放入随机红/蓝放置区

放置区位置只通过图像提供，不作为特权状态输入。holding 是实际夹持状态。夹爪解码规则为：dgrip <= -0.5 闭合，dgrip >= +0.5 张开，中间值保持。

## 正式数据整合

正式训练集为 data/v1.2_correction_64_close08_policy_ft70，由闭环纠偏数据和原始专家回放组成：

| 划分 | 场景数 | 样本数 | 内容 |
|---|---:|---:|---|
| train | 700 | 83,024 | 400 个闭环纠偏场景 + 300 个原始专家回放场景 |
| val | 300 | 33,080 | 100 个闭环纠偏场景 + 200 个原始验证场景 |
| test | 200 | 18,692 | 原始干净测试场景，未混入纠偏数据 |

数据整合策略和来源记录在 data/v1.2_correction_64_close08_policy_ft70/finetune_manifest.json。旧的 .08_safe 数据和模型不删除，作为回归与回退基线；失败的 policy.pt 不作为正式数据来源。

关键数据配置：图像 64×64，fine_tol=0.08，红/蓝方块与红/蓝放置区共 4 种指令组合。测试集保持干净，避免纠偏样本泄漏到最终闭环评测。
