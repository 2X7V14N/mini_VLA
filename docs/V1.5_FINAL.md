# V1.5 最终技术归档

## 目标与结论

V1.5 在 V1.3 的三色抓取放置任务上加入了动态性：被指令选中的方块与放置区在
episode 内持续移动，机器人需要根据最近的视觉历史、中文指令与自身状态完成
追踪、抓取、搬运和释放。

最终冻结模型是：

```text
checkpoints/v1.5e.pt
```

在独立、固定的双动态测试集上，V1.5e 达到 **1428 / 1800 = 79.3%** 完整成功率。
该结果是本项目的最终验收结果，不把后续未实施的 V1.6 或 V2.0 计划计入成果。

## 任务与推理接口

每个场景包含红、蓝、黄三块方块、三个位于不同位置的同色放置区，以及随机的
二维机器人起点。指令给出源方块颜色和目标放置区颜色。

```text
输入
  image_history  (4, 3, 64, 64)      最近 4 帧 RGB 图像
  instruction    中文字符序列          原始指令文本
  robot_state    [x, y, holding, gripper_open]

输出
  action_chunk   (4, 3)               预测的 4 步动作块
  action         [dx, dy, dgrip]      闭环时执行动作块第 1 步
```

`dx`、`dy` 是归一化二维移动，环境每 tick 乘以 `MAX_STEP=0.1`；`dgrip <= -0.5`
表示闭合、`dgrip >= 0.5` 表示张开，其余为保持。评测每一步都重新渲染图像、重新
前向推理并只执行第一个动作，因此不是开环回放专家轨迹。

## 最终模型

模型类为 `LanguageConditionedMiniVLA3ColorDynamicBoth`，实现位于
`src/mini_vla/models/mini_vla_v15c_dynamic.py`。

```text
4 帧 RGB
  -> 共享 VisionEncoder
  -> 每帧视觉 token 平均池化
  -> GRU 时间融合 + gated residual
中文指令
  -> 字符级 TextEncoder
机器人状态
  -> StateEncoder
视觉 + 语言 + 状态
  -> MultiModalFusion
  -> ActionHead
  -> 4 x [dx, dy, dgrip]
```

模型还训练了目标方块位置/速度、目标放置区位置/速度及未来目标区位置的辅助头。
这些头只提供训练监督；闭环执行仍由主动作头输出动作。真实坐标、速度、阶段和
颜色角色都不是模型推理输入。

## 数据与训练

正式数据位于本地的 `data/v1.5c/`（数据文件由 `.gitignore` 排除）：

| 划分 | 场景数 | 颜色组合 | 用途 |
|---|---:|---:|---|
| train | 1,000 | 每场景 9 种 | 监督训练 |
| val | 200 | 每场景 9 种 | 早停与模型选择 |
| test | 200 | 每场景 9 种 | 最终独立闭环验收 |

每个组合使用专家控制器录制；目标方块和目标放置区以每 tick `0.01–0.02` 的速度
匀速移动并在边界反弹。V1.5e 从 V1.5c 初始化，额外使用 V1.5c 在**训练场景**上
的闭环偏离纠正数据微调。验证集和测试集始终没有参与该纠正数据收集。

V1.5d 的阶段重采样/辅助头试验和 V1.5f 的第二轮纠正均未超过 V1.5e，因此它们
只作为否定实验记录保留，未被选为最终模型。

## 正式评测结果

测试固定为 `data/v1.5c/test` 的 200 个场景，针对 9 个源方块/目标区颜色组合
分别闭环，总计 1,800 条轨迹。结果机器可读文件为 `reports/v1.5e_results.json`。

| 指标 | V1.5c | V1.5e 最终 |
|---|---:|---:|
| 完整成功 | 1298/1800 (72.1%) | **1428/1800 (79.3%)** |
| 到达指定方块 | 99.5% | **99.6%** |
| 捕获目标 | 94.9% | **95.1%** |
| 到达放置区 | 89.0% | **92.7%** |
| `DROP_OUTSIDE` | 295 | **237** |
| `OBJECT_SLIPPED` | 107 | **43** |

剩余主要失败是最终释放：`DROP_OUTSIDE=237`。它说明模型通常能理解指令、接近
目标并完成搬运，但面对移动放置区时，释放时机与相对位置的闭环误差仍会累积。

## 复现与演示

权重和数据属于本地实验资产，未提交至 Git。它们存在时，可在仓库根目录运行：

```powershell
# 最终独立评测
python scripts\v1_5a\eval_v15c.py `
  --checkpoint checkpoints\v1.5e.pt `
  --data data\v1.5c `
  --scenes 200 `
  --out reports\v1.5e_results.json

# 本地交互可视化
python scripts\v1_5a\demo_v15e.py `
  --checkpoint checkpoints\v1.5e.pt `
  --interval 0.05
```

可视化在启动时创建一个完整动态场景，三块方块和三个放置区都会运动；在 GUI
底部输入指令并点击“执行”后，模型在同一场景中闭环执行；点击“新场景”可重复
体验。这个全对象运动模式比正式 V1.5e 测试更难，属于分布外演示，不能用其结果
替代上表 79.3% 的正式指标。

## 已知边界

- 环境是二维点机器人仿真，不是三维机械臂或真实硬件系统。
- 当前字符级语言模块只在三条中文训练模板和红/蓝/黄颜色角色上验证过，不能宣称
  具备开放域语言理解。
- 没有训练静态/动态障碍物规避；V1.6 的相关文档只是未来设计。
- Qwen 接入仅记录在 `docs/V2.0_PLAN.md`，未下载、训练或评测。
