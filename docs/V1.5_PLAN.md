# V1.5 计划：移动方块与移动放置区

## 一、版本目标

在已经通过验收的 V1.3 二维三色抓取放置任务上加入动态任务因素。V1.5 的核心不是静态障碍物，而是让目标方块和放置区在 episode 内连续移动，机器人仍需根据图像、语言指令和自身状态完成：

```text
识别指令指定的方块 → 追踪并抓取 → 搬运 → 追踪指定放置区 → 松开并完成放置
```

V1.5 分三个递进子阶段：

1. `V1.5a`：只有放置区移动，方块静止；
2. `V1.5b`：只有目标方块移动，放置区静止；
3. `V1.5c`：目标方块和放置区同时移动。

Checkpoint 统一使用短名：未训练动态基线为 `v1.5_init.pt`；各阶段的
最佳模型依次为 `v1.5a.pt`、`v1.5b.pt`、`v1.5c.pt`。不再把数据集、
任务描述或轮次写进 checkpoint 文件名。

当前实验路线按决策直接由 V1.5a 跳到 V1.5c；V1.5b 保留为可选的
单变量诊断实验，不作为 V1.5c 的前置条件。V1.5c 始终从 `v1.3_final.pt`
初始化，不继承 V1.5a 的时间模块，以免将 V1.5a 的释放阶段偏差带入双动态任务。

只有前一阶段通过独立验收后，才进入下一阶段。第一版不叠加静态障碍物、动态障碍物、多目标或开放域语言。

## 二、接口与约束

- 保留二维工作空间；
- 保留红、蓝、黄三种方块和三种放置区；
- 保留现有语言指令语义；
- 保留机器人状态接口 `[x, y, holding, gripper_open]`；
- 保留动作接口 `[dx, dy, dgrip]`；
- 每个场景只抓取一个方块并完成一次放置；
- 方块和放置区的位置每个 tick 连续更新，禁止瞬移；
- 初始方块、放置区和机器人位置随机；
- 推理时只输入图像、语言和机器人状态，不输入方块/放置区真实坐标或速度。

如果需要速度估计，模型使用连续图像或短历史窗口自行估计；仿真速度只能作为训练标签和专家生成信息。

## 三、动态运动模型

每个动态实体记录：

- 初始位置；
- 速度范围；
- 速度方向或轨迹类型；
- 最大加速度/转向变化；
- 边界反弹或安全边界规则；
- episode 内的完整真实轨迹。

运动规则必须在场景生成时固定并写入元数据。训练、验证和测试按完整场景划分，不能按 tick 随机拆分，避免同一运动轨迹泄漏到不同集合。

## 四、专家策略

专家需要处理两个动态阶段：

1. 预测并追踪移动方块，选择可抓取时机；
2. 抓取后预测移动放置区位置，选择释放时机。

专家应使用仿真真实位置和速度进行规划，但这些信息只用于生成专家动作、纠偏动作和辅助标签，不能作为模型推理输入。

每条专家轨迹必须满足：

- 目标追踪误差在抓取容差内；
- 抓取后方块没有滑落；
- 释放时方块中心落入指定放置区的 `official` 评分区域；
- 没有超时、过期观测或非法瞬移。

## 五、模型和训练方案

### V1.5a/b：最小改动

先在基础 V1.3 模型上加入短历史输入或相邻帧特征，使模型能够从视觉变化估计目标速度。保留原有语言条件动作头，先不引入强化学习。

训练目标包括：

```text
L = L_action
  + lambda_track * L_track
  + lambda_temporal * L_temporal
  + lambda_grip * L_grip
```

- `L_action`：专家动作监督；
- `L_track`：目标方块/放置区的视觉位置或追踪辅助监督；
- `L_temporal`：相邻帧预测的一致性和速度方向监督；
- `L_grip`：抓取和释放时机监督。

位置、速度和轨迹标签只参与训练损失，不会拼接为推理输入。

### V1.5c：同时移动

在 V1.5a 和 V1.5b 均通过后，训练同时移动的方块和放置区。此阶段加入：

- 更长的短历史窗口；
- 目标运动状态的时间一致性损失；
- 搬运阶段的未来放置区位置预测；
- 对抓取时机和释放时机的分阶段采样。

### V1.5e：闭环纠偏微调

V1.5d 的辅助头和阶段重采样实验未通过：双动态完整成功率由 V1.5c 的
72.1% 降至 70.7%，`DROP_OUTSIDE` 由 295 增至 312。因此 V1.5d 不作为
保留模型或后续初始化来源。

V1.5e 从 `v1.5c.pt` 初始化，模型架构和推理输入保持不变。改进不再来自
理想专家轨迹的重复加权，而是来自 V1.5c 在**训练场景**上的闭环偏离：

1. 回放 V1.5c，定位 `DROP_OUTSIDE`、`WRONG_ZONE` 和 `OBJECT_SLIPPED`；
2. 对每个失败 episode 保存进入 `OPEN` 前的实际偏离状态；
3. 从该状态由仿真专家生成能完成放置的纠偏子轨迹；
4. 微调时按 batch 级别混合原始专家数据与纠偏数据，验证集始终只使用原始
   V1.5c 的独立 `val` split。

纠偏记录仍只以图像、指令、机器人状态作为模型输入；真实坐标和环境 phase
只用于离线选择状态与生成动作标签。训练、验证和最终 1,800 条测试保持场景
隔离。

## 六、数据集设计

每个子阶段分别生成 `train/val/test`：

- 场景级划分，禁止 tick 级泄漏；
- 九种方块颜色到放置区颜色组合保持平衡；
- 覆盖静止、匀速、缓慢转向和边界反弹；
- 覆盖不同初始距离和相对运动方向；
- 包含成功专家轨迹和失败原因标签；
- 验证集、测试集不参与闭环纠偏数据收集。

必须记录：

- 方块和放置区真实位置、速度；
- 图像采样频率和动作频率；
- 追踪误差；
- 观测延迟和过期观测次数；
- 抓取/释放时机；
- 轨迹长度和总 tick 数。

## 七、评测指标

除总体成功率外，按阶段报告：

- `TARGET_NOT_REACHED`：未追上或未抓到目标方块；
- `ZONE_NOT_REACHED`：抓住后未追上放置区；
- `OBJECT_SLIPPED`：搬运中方块脱落；
- `DROP_OUTSIDE`：释放位置不在正式区域；
- `MAX_TICKS`：超时；
- `STALE_OBSERVATION`：使用过期观测后失败；
- 平均追踪误差；
- 抓取和释放时机误差；
- 九种颜色组合成功率；
- 方块静止/放置区移动/方块移动/双方移动四类成功率。

每个阶段还必须在 V1.3 无动态因素测试集上做回归，确认原有抓取放置能力没有明显退化，并继续使用 `official` 落点评分标准。

## 八、验收门槛

正式训练前先验证专家成功率接近 100%，并检查运动轨迹没有瞬移或标签泄漏。

阶段验收顺序：

1. `V1.5a`：移动放置区成功率达到目标，V1.3 回归通过；
2. `V1.5b`：移动方块成功率达到目标，V1.3 回归通过；
3. `V1.5c`：双方同时移动成功率达到目标，V1.5a/b 和 V1.3 回归均通过。

V1.5a 正式验收使用独立的 200 场景（1,800 条闭环）测试集，并同时满足：

- 专家在 train/val/test 三个 split 均为 100% 成功；
- 动态放置区完整成功率至少 75%，且不能低于未训练 V1.5a 初始化策略；
- 九种颜色组合中任一组合成功率不得低于 65%；
- 在 V1.3 `official` 静态基准上完整成功率至少 85%，防止动态微调破坏原有能力；
- 必须报告 `TARGET_NOT_REACHED`、`ZONE_NOT_REACHED`、`OBJECT_SLIPPED`、`DROP_OUTSIDE`、`MAX_TICKS` 的失败分布。

## 九、实施顺序

1. 保留并冻结 V1.3 正式 checkpoint 和 `official` 评测；
2. 实现动态方块/放置区环境和连续运动规则；
3. 实现专家追踪、抓取和释放策略；
4. 先生成并检查 V1.5a 数据；
5. 训练并评估 V1.5a，确认回归门槛；
6. 生成、训练和评估 V1.5b；
7. 生成、训练和评估 V1.5c；
8. 每个阶段完成后再决定下一阶段，不启动未验收阶段的正式训练。

## 十、后续路线

V1.5c 通过后，再定义 V1.6 的新难点。静态障碍物、动态障碍物和开放域语言不与 V1.5c 同时加入。V2.0 继续负责自然语言模板扩展、结构化语言解析和预训练语言编码器。
