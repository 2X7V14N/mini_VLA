# V1.3 Official Closed-Loop Evaluation Standard

V1.3 and subsequent versions use `official` as their single, shared closed-loop evaluation
standard. Future model comparisons for this task retain the same scoring rule
unless the user explicitly changes it.

| Metric | Threshold |
| --- | ---: |
| Enter `CLOSE` distance | `0.085` |
| Enter `OPEN` distance | `0.106` |
| `MOVE_TO_OBJECT` phase limit | `260 ticks` |
| `CLOSE` phase limit | `28 ticks` |
| `MOVE_TO_ZONE` phase limit | `400 ticks` |
| `OPEN` phase limit | `28 ticks` |
| Total ticks per rollout | `1950 ticks` |
| Final placement scoring area | Square, side length `0.30` |

Final scoring happens after the rollout: a trial succeeds only if the object was
released during `OPEN` and its center lies within `+/-0.15` on both axes from
the commanded zone center. The larger scoring square does not alter the rendered
scene, zone-approach rule, or robot actions. Grasp misses, slips during transport,
trials without a release during `OPEN`, and objects outside the scoring square
remain failures.

The environment retains its original `0.22` square for its internal result. The
evaluator records that environment result separately from the official score.
V1.3 model comparisons should use the same scene source and seed.

```powershell
python scripts\v1_3\eval_v13_closed_loop.py `
  --ckpt checkpoints\v1.3_final.pt `
  --scene-seed 20261105 `
  --scenes 200 `
  --ablation-scenes 0 `
  --failure-log reports\v1.3_state4_round3_targeted_ft_official_seed20261105_failures.json `
  --results-log reports\v1.3_state4_round3_targeted_ft_official_seed20261105_results.json
```

This command reproduces the selected V1.3 baseline comparison on the same
generated scene seed used for its acceptance result. New model comparisons
should use a fresh shared seed for all models being compared.
