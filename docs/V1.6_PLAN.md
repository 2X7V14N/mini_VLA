# V1.6 计划：静态障碍物上的双动态抓取放置（暂缓）

> 状态：暂缓。项目决定在 V1.5e 后直接进入 V2.0 的预训练语言模型阶段；
> 本文保留为未来障碍物扩展的设计记录，不生成数据、不训练，也不作为当前
> checkpoint 路线。

V1.6 以最终 `v1.5e.pt` 为起点，在保持移动方块和移动放置区任务的同时，
加入固定灰色障碍物。第一阶段只增加障碍物这一变量，不加入动态障碍物、强化
学习或开放域语言。

## 目标

机器人仍根据图像、语言和自身状态完成：选择指定方块、避开灰色障碍、抓取、
携带并放入移动目标区。推理时不得输入障碍物坐标、距离场或 A* 路点；坐标和
规划结果仅用于训练标签、专家轨迹和离线安全评估。

## 分阶段实施

1. **V1.6a 数据与专家**：在 V1.5c 场景生成固定矩形障碍，使用带碰撞检测的
   A* / 网格专家生成无碰撞抓取和搬运轨迹；先验证专家 100% 成功。
2. **V1.6a 感知辅助预训练**：从 V1.5e 迁移，增加障碍 mask 辅助头；mask 只
   通过视觉特征预测并参与训练 loss，不作为真实坐标输入。
3. **V1.6a 动作微调**：保持 V1.5e 的动作头和四帧历史，加入沿预测动作线段
   的碰撞安全损失、自由空间进度损失和 A* 下一路点方向监督；保留原始专家
   动作损失，防止模型学成停滞策略。
4. **V1.6b 泛化**：障碍位置、尺寸和数量随机化；先通过固定障碍回归，再测
   未见障碍布局。

## 验收门槛

- 专家 train/val/test 成功率 100%；
- 固定障碍闭环成功率不低于 V1.5e 在无障碍双动态任务的 79.3% 基线的明确
  任务化目标，且碰撞率低于 5%；
- 报告 `COLLISION`、`CARRY_COLLISION`、`DROP_OUTSIDE`、`OBJECT_SLIPPED`、
  `TARGET_NOT_REACHED` 和 `MAX_TICKS`；
- V1.5e 无障碍回归不明显退化；
- 固定障碍通过后才生成随机障碍泛化集。

当前只完成计划设计，不启动 V1.6 数据生成或训练；正式实施前先做环境、专家
和数据字段预检。
